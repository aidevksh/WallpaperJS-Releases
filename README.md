## Make room for your own desktop

WallpaperJS is a desktop application for running and managing your own web wallpapers. Import a local HTML / CSS / JavaScript project, add audio and pointer effects, and customize launcher icons in a charcoal and lavender interface.

This repository is the **public home for download documentation and future binary releases**. Application source is maintained separately in a private repository.

## Downloads

**No binary release is available yet.** The application is under development. A download and installation guide will be added here after the owner authorizes the first release.

There is no bundled wallpaper catalog. Wallpaper registration and curation are planned for a later stage.

## How it will work

1. Import your local web wallpaper project.
2. Select a display and apply the wallpaper.
3. Enable the project's audio and pointer inputs as needed.
4. On Windows, optionally choose a still frame or another image for the lock screen.

The lock screen remains the operating system's secure lock screen. WallpaperJS does not run web content there. macOS audio capture requires the applicable system permission.
